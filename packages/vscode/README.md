# MCD Commit Fuel

根据本地的开发节奏（提交、构建、测试、发版、收工），在 VS Code 状态栏安静地显示麦当劳积分、优惠券和按餐段推荐的餐品。

## 状态栏

| 状态 | 什么时候出现 | 显示 |
|---|---|---|
| 空闲 / 专注中 | 默认 | `🍟 1200分 · 6券` |
| 构建等待 | 构建或测试运行超过 3 分钟 | `⏳ 构建中 · 收藏门店 3 张券可用` |
| 卡 bug | 20 分钟内测试连续失败 3 次，或 1 小时内 revert 2 次 | 按餐段推荐，如下午 `☕ 下午茶？锡兰红茶 2kcal` |
| 刚发版 | 30 分钟内打了 release tag | `🎉 发版了 · 请团队吃一顿？` |
| 收工 | 今天有提交，且已空闲 90 分钟 | `🧾 收工了 · 今日小票` |

点击状态栏查看详情。推荐按餐段（早餐、午餐、下午茶、晚餐、夜宵）选择餐品，所有推荐都附热量；22:00 到 06:00 只推荐轻食和不含咖啡因的饮品。3 天内到期的券会单独提示，点击即可用券下单。

## 获取 token

1. 打开麦当劳 MCP 开放平台：<https://open.mcd.cn/mcp>
2. 点击右上角「登录」，用手机号完成验证登录。登录后右上角会变成「控制台」。
3. 点击「控制台」，在弹窗中点击「激活」申请 MCP token。
4. 阅读并同意服务协议。
5. 申请成功后点击一键复制 token。

更多说明见官方的 [麦当劳 MCP Server 使用指南](https://github.com/M-China/mcd-mcp-server)。

拿到 token 后运行命令 `MCD Fuel: 设置 MCP token` 粘贴即可。token 只保存在本机的 VS Code SecretStorage 中，不会写入任何配置文件。

## 命令

- `MCD Fuel: 设置 MCP token`：token 保存在 VS Code SecretStorage，不写入任何配置文件。
- `MCD Fuel: 查看详情` / `立即刷新` / `今日小票` / `清除 MCP token`
- `MCD Fuel: 点一份餐品（按餐段推荐，到店自取，需确认）`：选门店（收藏或搜索）→ 选餐品 → 算价 → 确认后下单，支付在麦当劳 App 中完成。
- `MCD Fuel: 请团队吃一顿（团餐外送，需确认）`：选人数（默认 2~4 人）→ 配送地址 → 门店 → 自动搭配 → 确认后下单。没有地址时请先在麦当劳 App 中添加。
- `MCD Fuel: 查看全部可用的券`：按临期 / 到店可用 / 仅外送分组，点击到店可用的券直接下单。
- `MCD Fuel: 领取可领的券（需确认）`：确认框列出可领的券，领完弹窗显示本次领到的券。

## 隐私

- 代码、diff、commit message、仓库名、作者邮箱都不会离开本机。commit message 只在本地用来判断是否是 revert。
- 终端命令只记录类别（构建 / 测试）、耗时和退出码。
- 自动刷新只调用只读接口；领券和下单只能手动触发，并需要在确认框中再次确认。
- 不受信任的工作区中不读取 git 记录。
